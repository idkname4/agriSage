# **App Name**: AgriVoice

## Core Features:

- Image Analysis: Upload images of leaves to identify potential diseases or pests using a pre-trained computer vision model.
- Voice Input & Output: Enable farmers to interact with the app using voice commands and receive spoken advice in multiple languages (Hindi, English, and a regional language).
- AI-Powered Recommendations: Provide localized and actionable recommendations for treatment, urgency, and prevention of crop issues, grounded in trusted sources using a RAG-enabled LLM tool.
- Offline Support: Allow farmers to capture and store images offline, and receive basic advice that will sync when connectivity is available.
- Agronomist Dashboard: Create a simple web-based dashboard for agronomists to review flagged images, model confidence levels, and escalate issues.
- WhatsApp Integration: Integrate the AI assistant into a WhatsApp bot (via Twilio) to facilitate easy access and interaction for farmers.
- Data Collection & Consent: Implement a clear consent flow for data collection and ensure basic user profile information (crop, location) is stored securely.

## Style Guidelines:

- Primary color: A warm, earthy orange (#E07A5F) evoking the richness of soil and harvest.
- Background color: A light beige (#F2E8CF), reminiscent of natural fibers and traditional agricultural materials.
- Accent color: A muted green (#3D405B), suggesting growth, health, and connection to nature; to be used sparingly for highlighting important information.
- Body and headline font: 'PT Sans', a humanist sans-serif offering a blend of modern clarity and approachability for optimal readability on diverse devices.
- Use clear and representative icons, with a hand-drawn aesthetic to emphasize approachability; focus on leaves, crops, pests, and farming activities.
- A simple, intuitive layout with a clear visual hierarchy, optimized for both voice and touch interactions; focus on large, easily tappable buttons and voice command prompts.
- Subtle, non-distracting animations to guide users through the interaction, such as a gentle pulsing effect on the voice input button or a smooth transition when displaying recommendations.
